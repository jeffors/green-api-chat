# Green API Chat

Это тестовое задание по созданию чата с использованием Green API.

## Как использовать?

Требуется аккаунт в MAX, а также необходим инстанс из Green API. Создать его можно здесь: https://green-api.com/max

## Как запустить?

Для локального запуска на устройстве трубуется Node.js

В папке проекта:

1. Установить зависимости командой `npm i`
2. Запустить проект командой `npm run dev`
